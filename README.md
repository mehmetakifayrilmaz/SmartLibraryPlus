
# 📚 Smart Library Plus (V2.0)

Bu proje, Veritabanı Programlama dersi final ödevi için hazırlanmıştır.
Java, Hibernate ORM ve SQLite veritabanı kullanılarak geliştirilmiştir.

## 🚀 Özellikler
1. **Kitap İşlemleri:** Ekleme, Listeleme, Silme, Düzenleme.
2. **Öğrenci İşlemleri:** Ekleme, Listeleme, Silme, Düzenleme.
3. **Ödünç Sistemi:** Kitap ödünç verme ve iade alma.
4. **Veritabanı:** SQLite (Otomatik tablo oluşturma).

## 📂 Proje Yapısı
- **entity:** Veritabanı tablolarına karşılık gelen sınıflar (Book, Student, Loan).
- **dao:** Veritabanı erişim nesneleri (CRUD işlemleri).
- **util:** Hibernate ayar ve bağlantı sınıfı.
- **app:** Ana uygulama ve konsol menüsü.

## 🛠️ Kurulum ve Çalıştırma
Proje Maven tabanlıdır.
1. Projeyi IDE (IntelliJ IDEA) ile açın.
2. Maven bağımlılıklarının yüklenmesini bekleyin.
3. `src/main/resources/hibernate.cfg.xml` dosyasının mevcut olduğundan emin olun.
4. `Main` sınıfını çalıştırın.
